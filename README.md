# Language World v2

## Файлы
- `index.html` — структура приложения.
- `style.css` — дизайн.
- `app.js` — логика: языки, тест, XP, игра, AI-демо.
- `words.js` — словарь.

## Важно про 1000+ слов
Файл `words.js` содержит архитектуру на 1000+ учебных записей. В этой демо-сборке записи после стартового набора помечены номерами — это НЕ 1000 уникальных переводов. Для настоящей версии их нужно заменить на 1000+ проверенных уникальных слов.

## AI
Кнопка `🤖 AI Учитель` сейчас работает в локальном демо-режиме. Настоящий AI следует подключать через серверный endpoint:
Браузер → твой сервер → AI API.
Никогда не вставляй секретный API-ключ прямо в `app.js`.

## GitHub Pages
1. Создай новый публичный репозиторий.
2. Загрузи все 4 файла в корень.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Сохрани и дождись публикации.
